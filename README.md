# 🤝 스마트 헬퍼 (Smart Helper)

> **어르신이 스마트폰과 키오스크를 스스로 쓸 수 있게 가르쳐 주고, 사기 문자로부터 지켜 주는 휴대폰 안 AI 도우미**

스마트폰이 서툰 고령 사용자를 위한 안드로이드 앱입니다. 세 가지 일을 합니다.

1. **🎤 말로 물어보기** — "사진 보내고 싶어요"라고 말하면, 연습용 가상 휴대폰이나 **실제 휴대폰 화면 위에 노란 테두리와 화살표**를 띄워 한 단계씩 직접 해 보게 안내합니다.
2. **🍽️ 키오스크 연습** — 음식점·병원·기차역 무인기를 실제와 똑같이 재현한 화면에서, 틀려도 괜찮게 연습합니다.
3. **🛡️ 문자 지킴이** — 문자·카카오톡으로 오는 **스미싱(문자 사기)을 받는 순간 감지**하고, 링크를 눌러도 **사이트가 열리기 전에 막고**, 직후 앱을 설치하려 하면 **설치 화면을 가리고 물어봅니다.**

- 대상: 스마트폰 사용이 서툰 어르신 (큰 글씨, 쉬운 존댓말, 음성 안내가 기본)
- 형태: 안드로이드 앱 (Android 8.0 이상) + 브라우저에서 바로 체험할 수 있는 웹 버전
- 목적: AI 경진대회 출품작

## 핵심 특징

| | |
|---|---|
| 🎓 **가르치는 AI** | 빅스비처럼 대신 해 주지 않고, 실제 앱 화면에서 "여기를 누르세요"를 짚어 주며 스스로 익히게 합니다 |
| 🧩 **연습 → 실전** | 가상 휴대폰·가상 키오스크에서 먼저 연습하고, 익숙해지면 내 휴대폰에서 안내를 받으며 직접 해 봅니다 |
| 🛡️ **위험한 순간마다 막는 사기 방어** | ① 문자·메신저를 **받는 순간** 감지 → ② 큰 글씨 경고와 음성 안내 → ③ 링크를 **누르면 사이트를 가로막음** → ④ 직후 앱을 **설치하려 하면 설치 화면을 가로막음** |
| 📱 **휴대폰 안에서만 동작하는 AI** | 직접 학습한 AI 모델이 휴대폰 안에서 판단합니다. 앱에 **인터넷 권한이 아예 없어** 문자·화면 내용이 밖으로 나갈 수 없습니다 |
| 🔒 **안전 설계** | 송금·결제는 돕지 않음, 화면을 볼 때는 항상 동의를 받고 🔴 표시, 엉뚱한 사람에게 보내지 않도록 받는 사람 확인 |

## 전체 기능

### 0. 모든 화면에 공통
| 기능 | 설명 |
|---|---|
| 🏠◀️🔁⏹️ **하단 고정 버튼 4개** | 처음 화면 · 이전 단계 · 다시 설명(마지막 안내를 다시 읽어 줌) · 도움 종료(화면 보기도 함께 끔) |
| 🔊 **음성 안내** | 모든 안내를 한국어 음성으로 천천히(0.85배속) 읽어 줌 |
| 🎤 **음성 입력** | 마이크 버튼으로 말해서 물어보기. 말이 어려우면 글로 쓰거나 **예시 버튼**을 눌러도 됨 |
| 🔒 **동의 창** | 화면을 보거나 문자를 읽기 전에 "허락해 주세요" 창으로 무엇을 왜 보는지 쉬운 말로 설명하고 허락받음 |
| ◀ **휴대폰 뒤로 가기** | 휴대폰의 뒤로 가기를 누르면 앱이 꺼지지 않고 "이전 단계"로 돌아감 |
| 🔠 **큰 글씨·큰 버튼** | 어르신 눈높이에 맞춘 글자 크기와 누르기 쉬운 큰 버튼 |

### 1. 🎤 말로 물어보기 — 휴대폰 사용법 안내
"영희한테 사진 보내고 싶어요", "아침 7시에 알람 맞추고 싶어요"처럼 말하거나 쓰면 알아듣고, 두 가지 방법 중에서 고를 수 있습니다.

**🎓 화면 속 휴대폰으로 연습하기** (가상 휴대폰)
- 앱 안에 **삼성 갤럭시(One UI) 모양**의 휴대폰 화면(홈, 메시지, 전화, 설정, 시계, Play 스토어, 연락처)을 그려 두고, 눌러야 할 곳에 **노란 테두리와 👇 화살표**를 띄웁니다. 큰 제목, 둥근 카드 메뉴, 켜고 끄는 스위치, "취소 | 저장" 막대, 확인 창까지 갤럭시처럼 만들었습니다.
- 메뉴 이름과 순서도 갤럭시와 같습니다. 예) 글자 크기: 설정 → 디스플레이 → 글자 크기와 스타일 / 음량: 설정 → 소리 및 진동 → 음량 / 앱 삭제: 설정 → 애플리케이션 → 앱 → 삭제 → 확인 / 연락처 삭제: 연락처 → ⋮ → 삭제
- 눌러야 할 곳이 화면 아래에 있으면 가상 휴대폰 화면을 스스로 굴려서 보여 줍니다.
- 동의를 받으면 "🔍 화면을 살펴보고 있어요"와 함께 화면을 훑는 모습을 보여 주고, 화면을 보는 동안 **🔴 / ⚪ 표시**로 상태를 알려 줍니다.
- 다른 화면으로 잘못 들어가면 "왼쪽 위 '뒤로'를 눌러 주세요"로 길을 다시 잡아 줍니다.
- 끝까지 해내면 "🎉 끝까지 해 내셨어요!"라고 칭찬하고 화면 보기를 끝냅니다.
- 은행 송금·이체는 연습도 안내도 하지 않습니다. "송금하고 싶어요"라고 하면 "송금은 안전을 위해 도와드리지 않아요"와 함께 직접 천천히 확인하고, 누가 시킨 송금이면 가족이나 112에 먼저 물어보라고만 알려 줍니다.

**📱 내 휴대폰으로 해 보기** (실제 화면 안내, 앱 전용)
- 실제 앱(문자, 설정, Play 스토어, 시계, 전화) 위에 노란 테두리·👇 화살표·큰 말풍선("2/4 '인터넷'을 눌러 주세요")을 띄우고 음성으로 안내합니다.
- 화면이 바뀌면 **지금 몇 단계인지 스스로 알아채** 다음 단계로 넘어가고, 이미 된 단계는 건너뜁니다(예: 와이파이가 이미 켜져 있으면 "켜기" 단계 생략).
- 사용자가 엉뚱한 곳을 누르면 "찾는 메뉴가 안 보이면 화면을 위로 밀어 보세요" 등으로 길을 잡아 줍니다.
- 맨 위에는 항상 **"🔴 스마트 헬퍼가 화면을 보고 있어요 [그만]"** 띠가 있고, 3분이 지나면 자동으로 멈춥니다.
- 이 휴대폰에서 할 수 없는 상황(예: 사진 문자 불가, Play 스토어 로그인 안 됨)은 알아채고 이유를 알려 준 뒤 멈춥니다.

### 2. 🍽️ 키오스크 연습
실제 무인 주문기처럼 생긴 화면에서 연습합니다.

**기기 모양**
- 첫 화면은 "👆 주문하시려면 화면을 눌러 주세요" **대기 화면**
- 위쪽에 가게 이름 띠, **남은 시간(⏱ 120초)**, **"가 큰 글씨"** 버튼, 지금 단계를 보여 주는 진행 표시(장소 › 메뉴 › 확인 › 결제…)
- 화면 아래에 **카드·QR 스캐너·지폐·신분증 투입구와 영수증 출력구**. 결제할 때는 고른 결제 수단에 맞는 투입구가 **노랗게 깜빡이고**, 그곳을 눌러야 "결제하고 있어요…" → "결제가 끝났어요"로 넘어감. 다른 투입구를 누르면 "그곳은 지폐 투입구예요"처럼 알려 줌
- 끝나면 출력구에서 **종이 영수증·접수표·승차권이 나오는 모습**과 주문번호·대기번호를 보여 줌

**연습 3가지**
| 키오스크 | 과정 |
|---|---|
| 🍜 **음식점 주문** | 매장/포장 → 카테고리 탭(추천·식사·사이드·음료)과 메뉴판(사진·가격·인기 표시) → **수량 팝업**(－ 1 ＋, 장바구니 담기) → **장바구니**(합계, ✕ 빼기) → 주문 확인 → 멤버십 적립(전화번호 키패드)·쿠폰 → 결제 수단 → 투입구 → 영수증 |
| 🏥 **병원 접수·수납** | 업무 선택에 따라 다른 흐름 — **진료 접수**: 진료과 → 의사 → 본인 확인(보험증·신분증 투입) → 확인 → 문자 알림 → 접수표 / **수납**: 금액 내역(진찰료·검사료·보험 부담) → 결제 / **증명서 발급**: 서류 선택 → 결제 → 출력 |
| 🚆 **기차표 예매** | 출발역 → 도착역(출발역과 같은 역은 막음) → 날짜(오늘부터 8일) → 인원(어른·어린이·경로 ＋/－) → **시간표**(매진 열차 표시) → **좌석표**(예약된 자리 회색, 창가 안내) → 결제 → 종이·모바일 승차권 |

**연습 방식**
- 연습 단계 4가지: **따라 하기**(눌러야 할 곳에 노란 테두리와 👆) · **연습하기**("다시 설명"을 누르면 힌트) · **혼자 하기** · **자유롭게**(목표 없이)
- 화면 위에 연습 목표를 보여 줌 (예: "매장에서 김치찌개 1개를 고르고, 멤버십을 적립한 뒤 카드로 결제해 보세요")
- 어떤 걸 골라도 진행되고, ◀ 이전 / ⌂ 처음으로 언제든 돌아갈 수 있음
- 남은 시간이 0초가 되어도 처음으로 돌리지 않고, "실제 키오스크는 한동안 누르지 않으면 처음 화면으로 돌아가요"라고 알려 준 뒤 이어서 하게 함
- 끝나면 "🎉 잘 하셨어요!"와 함께 **목표와 같게 고른 단계 수**를 보여 줌 (점수 매기기 없음)

### 3. 🛡️ 문자 지킴이 — 스미싱 방어 (앱 전용)

| 기능 | 설명 |
|---|---|
| 📩 **문자 자동 감시** | 새 문자가 오면 앱을 열어 두지 않아도 휴대폰 안에서 바로 검사. 연락처에 저장된 번호는 건너뜀. 긴 문자는 조각을 합쳐서 검사 |
| 💬 **카카오톡 지킴이** | 카카오톡·라인·텔레그램·페이스북 메신저·왓츠앱의 새 메시지 알림을 같은 방식으로 검사. 상대 이름이 연락처와 같아도 사칭일 수 있어 검사하고, 확실히 위험할 때만 알림 |
| 🚨 **경고 알림** | "🚨 위험한 문자예요! 링크를 누르지 마세요", 링크가 없는 사칭이면 "답장하지 마세요" |
| 📄 **큰 글씨 경고 화면** | 알림을 누르면 위험도(🚨 매우 위험 / ⚠️ 조심 / ✅ 낮음), 보낸 사람, 가린 문자 내용, **"왜 위험한가요?"**(규칙과 AI가 찾은 이유, AI 사기 가능성 %), **"이렇게 하세요"**(링크 누르지 않기, 문자 지우기, 112·118·1332)를 보여 주고 읽어 줌. 🔊 다시 듣기 |
| 🔗 **위험 링크 차단** | 사기로 판정된 메시지의 링크나 수상한 주소(IP 주소, `.apk`, `.xyz`·`.top`·`.site` 등)가 브라우저에서 열리면 **화면 전체를 빨간 경고로 가림**. 크게 "🛡️ 안전하게 나가기", 작게 "그래도 볼래요". 정상 사이트는 막지 않음 |
| ✋ **위험한 설치 막기** | 주의 이상 메시지를 받은 뒤 **30분(위험 시간대)** 안에 앱 설치 화면이나 '알 수 없는 앱 설치' 설정 화면을 열면, 화면 전체를 가리고 **"잠깐만요! 방금 받은 문자 때문에 설치하시는 건가요?"** 와 받은 시각·보낸 사람을 보여 주고 읽어 줌. 크게 "🛡️ 안전하게 그만두기"(설치 화면을 닫고 홈으로), "📞 가족에게 전화하기"(전화 앱에 번호만 띄움, 가족이 없으면 118), 작게 "그래도 진행"(5분 동안 다시 묻지 않음). **평소에는 아무것도 하지 않음** |
| 👨‍👩‍👧 **가족 연락처** | 문자 지킴이 화면에서 연락처 선택 창으로 가족 1명을 고름 (연락처 권한 없이도 가능) |
| ✍️ **직접 검사하기** | 다른 경로로 받은 수상한 글을 꾹 눌러 복사해 붙여 넣으면 같은 엔진으로 검사 (기록에 남기지 않음). 📋 예시 문자 넣기 버튼 |
| 📋 **최근 받은 문자 기록** | 판정 결과·보낸 사람·출처(문자/카카오톡 등)를 색깔로 구분해 보여 주고, 누르면 경고 화면. 긴 숫자는 가려서 저장, 🗑️ 기록 지우기 |
| ⚙️ **켜기 안내** | 🟢 켜짐 / ⚪ 꺼짐 상태를 보여 주고, 꺼져 있으면 동의 창 → 설정 화면으로 안내 (문자 지킴이 · 💬 카카오톡 지킴이 · 🔗 위험 링크·설치 차단) |

### 4. 🌐 웹 버전 (브라우저에서 바로 체험)
`index.html`을 크롬·엣지에서 열면 설치 없이 체험할 수 있습니다.
- 🎤 말로 물어보기(가상 휴대폰 연습), 🍽️ 키오스크 연습
- 🕵️ **수상한 문자 확인**: 문자를 붙여 넣거나 **샘플 캡처 사진 5종**(택배 반송·자녀 사칭·검찰 사칭·지원금 사칭·정상 문자)을 눌러 검사. "자동 감시 3단계" 검사 과정과 위험도·이유·대처법을 보여 줌
- 웹 버전은 규칙 검사만 사용합니다(AI 모델과 실제 화면 안내·자동 감시는 앱에서만 동작).

### 5. 🧩 시연·연습 도구
- **연습용 퍼즐** (`testapp`): 아무 기능 없는 빈 앱. "앱 지우기" 안내를 진짜 앱을 지우지 않고 안전하게 연습·시연할 때 설치해 둡니다.

## AI 활용 방식

### 스미싱 판단: 규칙 + 직접 학습한 AI 모델 (이중 판단)
```
문자 도착
  └ 1단계: 연락처에 저장된 번호? → 통과
  └ 2단계: 규칙 검사 (항상) — 사칭 말투, 돈·인증번호 요구, 링크 모양, 위험 단어
  └ 3단계: AI 모델 (링크가 없어도 항상 — "엄마 나 번호 바꿨어" 같은 링크 없는 지인 사칭 대비)
  └ 4단계: 내용 밖의 단서 — 누가, 처음인지, 조금 전에 무슨 문자를 보냈는지
  └ 점수를 합쳐 🚨 위험 / ⚠️ 주의 / ✅ 낮음
```

#### 내용 밖의 단서 (대화 흐름)
지인 사칭은 첫 문자에서 돈 얘기를 하지 않고, 몇 통 뒤에 요구합니다. 그래서 문자 한 통이 아니라 **흐름**을 봅니다.

| 단서 | 판단 | 대상 |
|---|---|---|
| **처음 문자를 보낸 번호**가 가족처럼 말함 ("할머니 저 손자예요") | ⚠️ 주의 이상 | 문자 |
| 해외 번호·[국제발신], 070 인터넷 전화 | 점수 +1 (혼자서는 경고 안 함) | 문자 |
| 24시간 안에 의심 문자를 보낸 상대가 **돈·상품권·인증번호·설치·링크**를 부탁 | 🚨 위험으로 올림 | 문자·메신저 |
| 24시간 안에 의심 문자를 보낸 상대의 다음 메시지 | 최소 ⚠️ 주의 유지 | 문자·메신저 |

- 예: "할머니 저 손자 준서예요 새로 개통한 번호라 저장 부탁드려요" → ⚠️ 주의 → 이어서 "상품권 하나만 부탁드려요" → 🚨 위험
- 상대를 몇 번 봤는지·언제 의심 문자를 보냈는지만 휴대폰 안에 기억하고, **번호·이름은 알아볼 수 없게(SHA-256) 바꿔 저장**합니다. 🗑️ 기록 지우기를 누르면 함께 지워집니다. 새 권한은 필요 없습니다.
- 메신저는 번호를 알 수 없고 앱을 켜기 전의 대화도 몰라서 '처음 온 번호' 단서는 문자에만 씁니다.
- **AI 모델**: 글자 조각(n-gram) 기반 로지스틱 회귀 분류기, **64KB**, 휴대폰 안에서 즉시 판단
- **학습 데이터**: 실제 스미싱 유형을 본뜬 **합성 문자 약 3,100개** (사기 47유형, 헷갈리기 쉬운 정상 문자 55유형 — 여러 호칭의 링크 없는 지인 사칭, 같은 호칭의 평범한 가족 문자, 진짜 인증번호·기관 안내·부고 포함)
- **고정 시험 문제**: 학습 틀과 따로 손으로 쓴 문자 233개, 학습에 절대 넣지 않음
  - `data/sms_holdout.tsv` 개발용 141개: 틀린 문자를 보고 규칙·학습 틀을 고치는 데 사용
  - `data/sms_final_test.tsv` 최종 시험 92개: 마지막에 점수만 확인
- **성능** (최종 시험 92개, 앱과 같은 규칙+AI 판단, ⚠️ 주의 이상을 경고로 봄)

  | | 개선 전 | 개선 후 |
  |---|---|---|
  | 정확도 | 82.6% | **96.7%** |
  | 정밀도 (경고 중 진짜 사기 비율) | 74.5% | **97.6%** |
  | 재현율 (사기 문자를 잡은 비율) | 95.3% | 95.3% |
- 규칙이 놓친 새 수법(예: 국민연금 사칭)도 AI가 잡아 "위험"으로 판정한 사례가 있습니다.

> ⚠️ 시험 문자도 개발자가 직접 쓴 것이라 성능 수치는 **합성 데이터 기준**입니다. 실제 문자에서는 다를 수 있으며, 실제 문자 데이터를 모아 다시 학습할 수 있게 만들어 두었습니다 (`data/sms_real.tsv`).

### 기본 문자 앱과 비교
스마트 헬퍼는 기본 문자 앱(삼성 메시지·구글 메시지)과 통신사 스팸 차단을 **대신하지 않고, 함께 켜 두는 두 번째 안전망**입니다. 기본 앱이 약한 부분을 어르신에게 맞춰 보완합니다.

> ⚠️ 아래 표는 기능을 비교한 것이며, **같은 문자로 탐지율을 직접 비교한 결과는 아직 없습니다**. 기본 앱의 기능은 기종·버전·통신사마다 다를 수 있습니다.

**기본 앱이 더 강한 부분**

| 항목 | 기본 문자 앱·통신사 | 스마트 헬퍼 |
|---|---|---|
| 데이터 규모 | 수많은 사용자의 실제 신고 문자로 학습 | 직접 만든 합성 문자 약 3,100개 |
| 최신 사기 링크 | 서버에서 위험 주소 목록을 실시간 갱신 | 인터넷 권한이 없어 새 사기 주소는 모름 (주소 모양으로만 판단) |
| 통신사 단계 차단 | 알려진 스미싱은 휴대폰에 오기 전에 걸러지기도 함 | 휴대폰에 도착한 뒤 검사 |
| 앱 설치 차단 | 갤럭시 '자동 차단기'를 켜면 출처를 모르는 앱 설치를 항상 막음 | 의심 메시지를 받은 뒤 30분 동안만 막음 |

**스마트 헬퍼가 보완하는 부분**

| 항목 | 기본 문자 앱·통신사 | 스마트 헬퍼 |
|---|---|---|
| 링크 없는 지인 사칭 | 링크·번호 평판 중심이라 놓치기 쉬움 | 처음 온 번호의 가족 말투 → ⚠️ 주의, 이어진 상품권·인증번호 요구 → 🚨 위험 (대화 흐름) |
| 설명 방식 | 주로 "스팸 의심" 표시 | 큰 글씨·쉬운 말·음성으로 "왜 위험한가요? / 이렇게 하세요" |
| 메시지와 행동 연결 | 메시지 판단과 설치·링크 차단이 따로 동작 | 위험 메시지의 링크가 브라우저에서 열리면 가림, 의심 메시지 뒤 설치 시도를 막고 가족 전화 버튼 제공 |
| 메신저 | 문자 앱은 문자만 검사 | 카카오톡·라인 등 메신저 알림도 같은 엔진으로 검사 |
| 개인정보 | 서버 조회를 쓰는 경우가 있음 | 문자를 휴대폰 밖으로 보내지 않음, 인터넷 권한 없음 |

**비교 실험 계획** (시연 폰 확보 후)
1. 경찰청·한국인터넷진흥원(KISA) 보도자료의 실제 스미싱 문구 30~50개와 정상 문자를 모은다. 링크는 가짜 주소로 바꾼다.
2. 다른 휴대폰에서 시연 폰으로 보내, 기본 문자 앱의 스팸 표시 여부와 스마트 헬퍼의 판정을 표로 기록한다.
3. 특히 **링크 없는 지인 사칭**에서 차이가 나는지 확인한다.

## 안전과 개인정보

1. **인터넷 권한 없음** — 문자, 메시지, 화면 내용이 휴대폰 밖으로 나가지 않습니다.
2. **송금·결제는 돕지 않습니다.** "송금하고 싶어요"라고 하면 직접 하시도록 안내하고, 누가 시킨 송금이면 가족에게 먼저 물어보라고 알려 줍니다.
3. **동의 후에만 화면을 봅니다.** 화면을 보는 동안에는 🔴 "스마트 헬퍼가 화면을 보고 있어요" 띠와 **그만** 버튼이 항상 떠 있고, 3분이 지나면 자동으로 멈춥니다.
4. **필요한 앱만 봅니다.** 화면 안내는 문자·설정·Play 스토어·시계·전화 앱만, 링크 차단은 브라우저 **주소창만**, 설치 차단은 **위험 시간대에만** 앱 설치 화면과 '알 수 없는 앱 설치' 설정 화면의 **설치 여부를 묻는 글자만** 봅니다. 메신저는 정해진 메신저 앱의 알림만 읽습니다.
   - 설치 화면은 패키지 이름만 믿지 않고 화면 글자("이 앱을 설치하시겠습니까", "설치", "이 출처 허용" 등)도 함께 확인합니다.
5. **받는 사람 확인** — 문자·사진·전화 안내는 화면의 받는 사람 이름·번호가 맞을 때만 진행하고, 다르면 즉시 멈춥니다. (시험 중 끝자리가 같은 사기 번호 대화창이 열린 것을 이 장치가 막았습니다.)
6. **사칭 대비** — 메신저 상대 이름이 연락처와 같아도 검사는 하고, 확실히 위험할 때만 알립니다(사기꾼이 프로필 이름을 "아들"로 바꿀 수 있기 때문).
7. **가려서 저장** — 기록에는 6자리 이상 숫자를 `●●●●●●`로 가린 내용만 남깁니다.
8. **공식 스토어만** — 앱 설치는 Play 스토어에서만, 별점·다운로드 수를 확인하도록 안내합니다.

## 실행 방법

### 웹 버전 (가장 간단)
`index.html`을 크롬이나 엣지에서 열면 됩니다.

### 안드로이드 앱
1. Android Studio에서 `android` 폴더를 엽니다.
2. 휴대폰을 연결하고 실행(▶)합니다. 또는 `android` 폴더에서:
   ```
   gradlew assembleDebug
   adb install -r app\build\outputs\apk\debug\app-debug.apk
   ```
3. 앱의 **문자 지킴이** 화면에서 기능을 켭니다. 사용자가 직접 허용해야 하는 항목:

| 권한 | 쓰는 곳 |
|---|---|
| 문자 수신 | 새 문자 자동 감시 |
| 연락처 읽기 | 저장된 번호 건너뛰기, "영희"를 연락처에서 찾기 |
| 알림 | 위험 문자 경고 |
| 접근성(화면 안내) | 실제 화면 안내, 위험 링크 차단, 위험한 설치 막기 |
| 알림 읽기 | 카카오톡 등 메신저 감지 |

### 테스트
```
gradlew :app:testDebugUnitTest
```
AI 모델 다시 학습: `gradlew :app:testDebugUnitTest --tests "*ModelTrainer*" -Ptrain=1`
