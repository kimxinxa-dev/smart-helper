# 🤝 스마트 헬퍼 (Smart Helper)

> **어르신이 스마트폰을 스스로 쓸 수 있게 가르쳐 주고, 사기 문자로부터 지켜 주는 휴대폰 안 AI 도우미**

스마트폰이 서툰 고령 사용자를 위한 안드로이드 앱입니다. 대신 해 주는 비서가 아니라, **실제 휴대폰 화면 위에 노란 테두리와 화살표를 띄워 한 단계씩 직접 해 보게 안내**합니다. 그리고 문자·카카오톡으로 오는 **스미싱(문자 사기)을 받는 순간 감지하고, 링크를 눌러도 사이트가 열리기 전에 막습니다.**

- 대상: 스마트폰 사용이 서툰 어르신 (큰 글씨, 쉬운 존댓말, 음성 안내가 기본)
- 형태: 안드로이드 앱 (Android 8.0 이상)
- 목적: AI 경진대회 출품작

---

## 핵심 특징

| | |
|---|---|
| 🎓 **가르치는 AI** | 빅스비처럼 대신 해 주지 않고, 실제 앱 화면에서 "여기를 누르세요"를 짚어 주며 스스로 익히게 합니다 |
| 🛡️ **3중 사기 방어** | ① 문자·메신저를 **받는 순간** 감지 → ② 큰 글씨 경고와 음성 안내 → ③ 그래도 링크를 **누르면 사이트를 가로막음** |
| 📱 **휴대폰 안에서만 동작하는 AI** | 직접 학습한 AI 모델이 휴대폰 안에서 판단합니다. 앱에 **인터넷 권한이 아예 없어** 문자·화면 내용이 밖으로 나갈 수 없습니다 |
| 🔒 **안전 설계** | 송금·결제는 돕지 않음, 화면을 볼 때는 항상 동의를 받고 🔴 표시, 엉뚱한 사람에게 보내지 않도록 받는 사람 확인 |

## 주요 기능

홈 화면은 **말로 물어보기 / 키오스크 연습 / 문자 지킴이** 세 가지입니다. 화면 아래에는 항상 **처음 화면 · 이전 단계 · 다시 설명 · 도움 종료** 버튼이 있습니다.

### 1. 🎤 말로 물어보기 — 휴대폰 사용법 안내
"영희한테 사진 보내고 싶어요"처럼 말하거나 쓰면, 두 가지 방법 중에서 고를 수 있습니다.

- **🎓 화면 속 휴대폰으로 연습하기**: 앱 안의 가상 휴대폰에서 틀려도 괜찮게 연습
- **📱 내 휴대폰으로 해 보기**: 실제 앱(문자, 설정, 시계 등) 위에 노란 테두리·👇 화살표·큰 말풍선을 띄우고 음성으로 한 단계씩 안내. 화면이 바뀌면 다음 단계를 스스로 알아채고, 잘못 들어가면 길을 다시 잡아 줍니다.

| 할 일 | 연습 | 실제 화면 안내 |
|---|:---:|:---:|
| 문자로 사진 보내기 | ✅ | ✅ (받는 사람 확인) |
| 문자 보내기 | ✅ | ✅ (받는 사람 확인) |
| 전화 걸기 | ✅ | 🔧 만드는 중 (시험 전) |
| 알람 맞추기 (시계판에서 시→분→오전/오후를 하나씩 짚어 줌) | ✅ | 🔧 단계 안내 확인, 완료 판단 보완 중 |
| 와이파이 연결 | ✅ | ✅ |
| 글자 크기 키우기·줄이기 | ✅ | ✅ |
| 앱 설치 (Play 스토어, 공식 앱만) | ✅ | ✅ |
| 앱 지우기 | ✅ | ✅ |
| 음량 조절, 연락처 추가·삭제 | ✅ | — |
| 은행 송금 | 안전 안내만 | ❌ 돕지 않음 |

### 2. 🍽️ 키오스크 연습
실제 무인 주문기처럼 생긴 화면에서 연습합니다. 대기 화면, 남은 시간, 큰 글씨 버튼, 그리고 화면 아래 **카드·QR·지폐·신분증 투입구와 영수증 출력구**까지 재현했습니다.

- **음식점 주문**: 카테고리 탭, 메뉴판, 수량 팝업, 장바구니, 멤버십 적립, 결제
- **병원 접수·수납**: 진료 접수 / 수납 / 증명서 발급별로 다른 흐름
- **기차표 예매**: 출발·도착역, 날짜, 인원, 시간표(매진 표시), 좌석표
- 연습 단계 4가지: 따라 하기(화살표) · 연습하기(힌트) · 혼자 하기 · 자유롭게
- 어떤 걸 골라도 진행되고, 언제든 이전 단계로 돌아갈 수 있습니다. 남은 시간이 0초가 되어도 처음으로 돌리지 않고 "실제 키오스크라면 처음으로 돌아가요"라고 알려만 줍니다.

### 3. 🛡️ 문자 지킴이 — 스미싱 방어

| 기능 | 설명 |
|---|---|
| 📩 **문자 자동 감시** | 새 문자가 오면 휴대폰 안에서 바로 검사. 연락처에 저장된 번호는 건너뜀 |
| 💬 **카카오톡 지킴이** | 카카오톡·라인·텔레그램·페이스북 메신저·왓츠앱의 새 메시지 알림을 같은 방식으로 검사 |
| 🚨 **경고** | 위험하면 알림 → 누르면 큰 글씨 경고 화면에서 이유와 대처법(112, 118, 1332)을 보여 주고 읽어 줌 |
| 🔗 **위험 링크 차단** | 사기로 판정된 메시지의 링크나 수상한 주소(IP 주소, `.apk`, `.xyz` 등)가 브라우저에서 열리면 **화면 전체를 가리고** "안전하게 나가기"로 빠져나오게 함 |
| ✍️ **직접 검사** | 다른 경로로 받은 수상한 글을 붙여 넣으면 같은 엔진으로 검사 (기록에 남기지 않음) |
| 📋 **기록** | 최근 받은 문자·메시지의 판정 결과. 계좌번호 같은 긴 숫자는 가려서 저장 |

## AI 활용 방식

### 스미싱 판단: 규칙 + 직접 학습한 AI 모델 (이중 판단)
```
문자 도착
  └ 1단계: 연락처에 저장된 번호? → 통과
  └ 2단계: 규칙 검사 (항상) — 사칭 말투, 돈·인증번호 요구, 링크 모양, 위험 단어
  └ 3단계: AI 모델 (링크가 있거나 규칙에 걸린 문자만 — 배터리 절약)
  └ 점수를 합쳐 🚨 위험 / ⚠️ 주의 / ✅ 낮음
```
- **AI 모델**: 글자 조각(n-gram) 기반 로지스틱 회귀 분류기, **46KB**, 휴대폰 안에서 즉시 판단
- **학습 데이터**: 실제 스미싱 유형을 본뜬 **합성 문자 약 2,300개** (사기 39유형, 헷갈리기 쉬운 정상 문자 36유형)
- **성능** (학습에 쓰지 않은 유형으로 평가): **정확도 92%, 사기 문자 재현율 100%**
- 규칙이 놓친 새 수법(예: 국민연금 사칭)도 AI가 잡아 "위험"으로 판정한 사례가 있습니다.

> ⚠️ 성능 수치는 **합성 데이터 기준**입니다. 실제 문자에서는 다를 수 있으며, 실제 문자 데이터를 모아 다시 학습할 수 있게 만들어 두었습니다 (`data/sms_real.tsv`).

### 화면 이해
- 말 이해: 구어체에서 할 일·이름·시간을 뽑는 규칙 기반 해석기 (예: "우리 아들 민수에게" → 아들 민수, "저녁 일곱 시 반" → 19:30)
- 화면 인식: 안드로이드 접근성 기능으로 버튼의 이름·위치를 읽어 지금 단계를 판단

### 앞으로: 휴대폰 안 소형 언어모델 (계획)
Gemma 계열 약 1B 모델로 위험 이유를 상황에 맞는 쉬운 말로 설명하고, 규칙이 못 알아들은 말을 해석하는 기능을 계획하고 있습니다. 실제 휴대폰(RAM 6GB 이상)에서 시연할 예정입니다.

## 안전과 개인정보

1. **인터넷 권한 없음** — 문자, 메시지, 화면 내용이 휴대폰 밖으로 나가지 않습니다.
2. **송금·결제는 돕지 않습니다.** "송금하고 싶어요"라고 하면 직접 하시도록 안내하고, 누가 시킨 송금이면 가족에게 먼저 물어보라고 알려 줍니다.
3. **동의 후에만 화면을 봅니다.** 화면을 보는 동안에는 🔴 "스마트 헬퍼가 화면을 보고 있어요" 띠와 **그만** 버튼이 항상 떠 있고, 3분이 지나면 자동으로 멈춥니다.
4. **필요한 앱만 봅니다.** 화면 안내는 문자·설정·Play 스토어·시계·전화 앱만, 링크 차단은 브라우저 **주소창만** 봅니다. 메신저는 정해진 메신저 앱의 알림만 읽습니다.
5. **받는 사람 확인** — 문자·사진·전화 안내는 화면의 받는 사람 이름·번호가 맞을 때만 진행하고, 다르면 즉시 멈춥니다. (시험 중 끝자리가 같은 사기 번호 대화창이 열린 것을 이 장치가 막았습니다.)
6. **사칭 대비** — 메신저 상대 이름이 연락처와 같아도 검사는 하고, 확실히 위험할 때만 알립니다(사기꾼이 프로필 이름을 "아들"로 바꿀 수 있기 때문).
7. **가려서 저장** — 기록에는 6자리 이상 숫자를 `●●●●●●`로 가린 내용만 남깁니다.
8. **공식 스토어만** — 앱 설치는 Play 스토어에서만, 별점·다운로드 수를 확인하도록 안내합니다.

## 실행 방법

### 웹 시뮬레이션 (가장 간단)
`index.html`을 크롬이나 엣지에서 열면 됩니다. 말로 물어보기(연습), 수상한 문자 확인, 키오스크 연습을 체험할 수 있습니다.

### 안드로이드 앱
1. Android Studio에서 `android` 폴더를 엽니다.
2. 휴대폰을 연결하고 실행(▶)합니다. 또는 `android` 폴더에서:
   ```
   gradlew assembleDebug
   adb install -r app\build\outputs\apk\debug\app-debug.apk
   ```
3. 앱의 **문자 지킴이** 화면에서 기능을 켭니다. 사용자가 직접 허용해야 하는 항목:

| 권한 | 쓰는 곳 |
|---|---|
| 문자 수신 | 새 문자 자동 감시 |
| 연락처 읽기 | 저장된 번호 건너뛰기, "영희"를 연락처에서 찾기 |
| 알림 | 위험 문자 경고 |
| 접근성(화면 안내) | 실제 화면 안내, 위험 링크 차단 |
| 알림 읽기 | 카카오톡 등 메신저 감지 |

### 테스트
```
gradlew :app:testDebugUnitTest
```
AI 모델 다시 학습: `gradlew :app:testDebugUnitTest --tests "*ModelTrainer*" -Ptrain=1`

## 현재 한계와 앞으로 할 일

**아직 확인하지 못한 것** (가상 휴대폰에서 시험했고, 실제 휴대폰에서 확인 예정)
- 삼성 갤럭시의 문자·설정·시계·전화 앱에서 실제 화면 안내 (구글 기본 앱 기준으로 만들고, 삼성 메뉴 이름도 함께 찾도록 해 둠)
- 실제 카카오톡 알림 감지 (시험용 알림으로 확인)
- 사진 문자 보내기 마지막 단계 (가상 휴대폰은 사진 문자 불가), 앱 설치 안내의 검색·설치 단계 (구글 로그인 필요)
- 알람 안내의 완료 판단, 전화 걸기 안내
- 마이크 음성 인식

**알려진 한계**
- 말 이해는 규칙 기반이라 예상한 표현 위주로 알아듣습니다.
- 카카오톡 안에서 바로 열리는 웹 화면은 아직 막지 못합니다 (크롬·삼성 인터넷·웨일 등 브라우저만).
- AI 모델 성능은 합성 데이터 기준입니다.

**계획**
- 휴대폰 안 소형 언어모델(Gemma 계열)로 쉬운 말 설명
- 실제 문자 데이터로 AI 모델 다시 학습
- 사진 속 글자 인식(OCR)으로 캡처 이미지 검사
- 수상한 앱 설치 경고, 가족 알림
